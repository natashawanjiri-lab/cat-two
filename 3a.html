CSS Selectors Explained

Element Selector

This paragraph is styled by the element selector p. All paragraphs look like this.

Class Selector

This paragraph uses class="highlight" so it has a yellow background.

This paragraph does NOT have the class, so it has no yellow background.

ID Selector

The main title at the top uses id="main-title" so it is green and centred. IDs are unique - only one per page.

Group Selector

Both h2 and h3 headings are dark blue because we grouped them: h2, h3.
